Waskita rilis sistem pembayaran terintegrasi demi permudah mitra kerja

PT Waskita Karya (Persero) Tbk (WSKT) memanfaatkan layanan Application Programming Interface (API) PT Bank Negara Indonesia (Persero) Tbk (BNI) berstandar Nasional Open API (SNAP), meluncurkan sistem Host to Host (H2H) pembayaran terintegrasi di Jakarta, Rabu (02/09/2026). (ANTARA/HO-WSKT)
										
									              
								Hal ini sejalan dengan transformasi Waskita yang mengacu pada delapan streamJakarta (ANTARA) - PT Waskita Karya (Persero) Tbk (WSKT) meluncurkan sistem Host to Host (H2H) pembayaran terintegrasi, sebagai upaya mempermudah proses pembayaran mitra kerja seiring kemudahan sistem digital yang disediakan.

Adapun, perseroan memanfaatkan layanan Application Programming Interface (API) PT Bank Negara Indonesia (Persero) Tbk (BNI) yang telah berstandar Nasional Open API (SNAP).
