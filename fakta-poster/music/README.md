# 🎵 Lagu buat reel (auto-mix)

> **Udah diisi 5 lagu** (Kevin MacLeod, CC BY 4.0 — lihat `CREDITS.txt`).
> Kredit otomatis ditempel ke caption **reel** (carousel tetap bersih).
> Mau nambah/ganti? Ikutin panduan di bawah.

Taruh file lagu **royalty-free** di folder ini. Tiap kali bikin reel, pipeline
(`daily_fakta.py`) **pilih satu lagu acak** dari sini, lalu di-tempel ke video
otomatis (di-loop/trim ke 20 detik, volume diturunin, fade-out di akhir).

- Format didukung: `.mp3`, `.m4a`, `.aac`, `.wav`, `.ogg`
- Kalau folder ini **kosong** → reel tetep dibuat tapi **senyap** (aman, gak error).
- File harus **ke-commit** ke repo biar workflow di GitHub bisa pakai
  (jangan kegedean — idealnya tiap lagu < 5 MB).

## ⚠️ WAJIB royalty-free (bebas hak cipta + boleh komersil)

JANGAN pakai lagu trending/komersil (Spotify, TikTok sound, dll) di sini —
itu di-burn ke video → kena copyright (IG mute/takedown/strike). Lagu trending
cuma boleh dipasang **manual lewat app IG**.

### Sumber lagu gratis yang AMAN (boleh monetisasi, no copyright):
- **YouTube Audio Library** — studio.youtube.com → Audio Library → filter
  "No attribution required". Download mp3.
- **Pixabay Music** — pixabay.com/music (bebas, no attribution)
- **Free Music Archive** — freemusicarchive.org (cek lisensi CC0 / CC-BY)
- **Uppbeat / Mixkit** — banyak track gratis buat konten

### Vibe yang cocok buat reel fakta:
Instrumental **upbeat / penasaran / sinematik ringan**, tempo sedang,
**tanpa vokal** (biar gak nabrak teks). Tag yang dicari: *curious, inspiring,
documentary, lo-fi, ambient, corporate upbeat, cinematic*.

Cukup taruh **3–8 lagu** di sini biar variasi (gak monoton tiap hari).
